# Školski IT Klub / Coding Club

Prezentacijska web stranica školskog kluba za programiranje i tehnologiju izrađena u sklopu projektnog zadatka iz predmeta **Softversko inženjerstvo** (4. razred gimnazije - IT smjer).

## Korištene tehnologije
- HTML5
- CSS3 (responzivan dizajn)
- JavaScript (validacija kontakt forme)
- Git & GitHub (verzionisanje i rad na odvojenim granama)

## Struktura projekta
- `index.html` - Glavna struktura web stranice
- `style.css` - Stilovi i responzivni izgled
- `script.js` - Validacija kontakt forme
- `docs/` - Wireframe i mockup dokumentacija
- `images/` - Slike korištene u projektu

## Kako pokrenuti projekt
1. Klonirati repozitorij: `git clone <URL-repozitorija>`
2. Otvoriti `index.html` u bilo kojem web pregledniku.
